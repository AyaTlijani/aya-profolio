03 / PROJECTS

Things I've made.

01 NLP · RAG · LLM

SciLit

RAG System for Verified Literature Reviews.

Built an end-to-end RAG system that answers research questions over 1,109 NLP papers, combining hybrid retrieval (BM25 + dense embeddings) with a local LLM that writes cited literature reviews.

Added an automatic fact-checking step that verifies every generated sentence against the source papers: 95% of sentences pass, each linked to its exact source.

Fine-tuned SciBERT for scientific sentence classification (0.749 macro-F1) and reproduced a published benchmark result (0.855 F1).

TECH STACK ✦
Python PyTorch Hugging Face RAG LLMs FastAPI
02 LLM AGENTS / TEXT-TO-SQL

QueryPilot

Self-Correcting Text-to-SQL Agent.

Built a LangGraph-based LLM agent that generates SQL from natural-language questions, executes queries, and automatically diagnoses and repairs failures.

Evaluated on 200 BIRD Mini-Dev questions across 11 databases using Qwen2.5-Coder 7B and Gemini API; improved execution accuracy from 47% to 51% with Qwen and from 62.5% to 64% with Gemini.

Implemented a read-only SQL sandbox, tested against 16 write and injection attacks, and exposed database tools to other AI assistants through an MCP server.

TECH STACK ✦
Python LangGraph LLMs SQL MCP
